# QUICK·BOOTH

复古风格的大头贴（Photo Booth）网页应用。使用摄像头拍照，套用复古模版，导出打印 / PDF / PNG。

## 使用说明

1. 点击「启动」打开摄像头，按下快门拍照（最多 4 张）
2. 切换到「模版」步骤，选择喜欢的布局
3. 可选添加个性文字和时间戳
4. 切换到「导出」步骤，打印、保存 PDF 或下载 PNG


## 功能一览

- 拍摄闪光灯 + 机械快门音效
- 自拍定时器（3s / 5s / 10s）
- 实时滤镜（黑白 / 暖色 / 冷色 / 复古 / 富士）
- 一键连拍
- 7 套模版 — 经典四格 / 经典三格 / 2×2 宫格 / 拍立得 / 证件照 / 胶卷 / 明信片
- 个性文字（每个模版独立定位）
- 时间戳水印
- 导出：打印 / PDF（jsPDF）/ PNG
- 复古胶片相机界面（皮革、黄铜、取景器、胶卷条）

## 技术栈

纯 JavaScript（ES Module）+ Canvas API。无框架依赖。
