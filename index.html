📷 QUICK·BOOTH

VINTAGE PHOTO STUDIO · TYPE-R

使用说明
  1. 点击「启动」打开摄像头，调整姿势后按快门拍照
  2. 最多拍摄 4 张，可单独删除不满意的照片
  3. 切换到「模版」步骤，选择喜欢的布局样式
  4. 可选添加个性文字和时间戳水印
  5. 在「导出」步骤打印、保存 PDF 或下载 PNG
功能一览
  • 📸 闪光灯 + 机械快门音效
  • ⏱ 自拍定时器（3s / 5s / 10s）
  • 🎨 实时滤镜（黑白 / 暖色 / 冷色 / 复古 / 富士）
  • ⚡ 一键连拍
  • 🎞 7 套模版（经典四格 / 三格 / 宫格 / 拍立得 / 证件照 / 胶卷 / 明信片）
  • 🖨 打印 / 📄 PDF / ⬇ PNG 导出
